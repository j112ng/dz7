##  Вариант 8

### Условие задачи
Определить, на какой день недели приходится 1 сентября произвольно заданного года XXI века. Использовать конструкцию if-else не рекомендуется.

### 1. Алгоритм и блок-схема

**Алгоритм:**
1. Начало.
2. Ввести год `year`.
3. Проверить, входит ли год в диапазон XXI века (2001–2100). Если нет — вывести ошибку и завершить программу.
4. Обнулить счетчик общего количества дней `total_days`.
5. Запустить цикл подсчета дней с 2001 года до введенного `year - 1`.
6. Определить, является ли текущий год цикла високосным, и прибавить к `total_days` 365 или 366 дней.
7. Прибавить к `total_days` количество дней с января по август (243 дня).
8. Проверить, является ли високосным сам введенный `year`, и при необходимости добавить еще 1 день.
9. Вычислить день недели как остаток от деления `total_days % 7`.
10. С помощью конструкции `switch` вывести на экран название дня недели.
11. Конец.

### 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>
#include <stdlib.h>

int main() {
    system("chcp 65001 > nul"); 
    setlocale(LC_ALL, "RUS");

    int year;
    printf("Введите год 21 века (2001-2100): ");
    scanf("%d", &year);

    if (year < 2001 || year > 2100) {
        printf("Ошибка: год должен быть в пределах 21 века.\n");
        return 0;
    }

    int total_days = 0;

    for (int y = 2001; y < year; y++) {
        int is_leap = (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
        total_days += 365 + is_leap;
    }

    total_days += 31 + 28 + 31 + 30 + 31 + 30 + 31 + 31;
    
    int is_leap_current = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
    total_days += is_leap_current;

    int day_of_week = total_days % 7;

    switch (day_of_week) {
        case 0: 
            printf("1 сентября %d года — это понедельник.\n", year); 
            break;
        case 1: 
            printf("1 сентября %d года — это вторник.\n", year); 
            break;
        case 2: 
            printf("1 сентября %d года — это среда.\n", year); 
            break;
        case 3: 
            printf("1 сентября %d года — это четверг.\n", year); 
            break;
        case 4: 
            printf("1 сентября %d года — это пятница.\n", year); 
            break;
        case 5: 
            printf("1 сентября %d года — это суббота.\n", year); 
            break;
        case 6: 
            printf("1 сентября %d года — это воскресенье.\n", year); 
            break;
    }

    return 0;
}
```
